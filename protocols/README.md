- `METHOD_FREEZE_v1.0.md`: core conditions, model roles, cut/stop rules.
- `STATISTICAL_ANALYSIS_SPEC_v1.0.md`: primary metric, bootstrap, paired deltas.
- `H07_NEURAL_IMPLEMENTATION_CLARIFICATIONS_v1.0.md`: BERTweet training details.
- `H08_STATS_ERROR_SPEC_v1.0.md`: uncertainty and qualitative-pilot specification.
- `H10_EXTERNAL_TRANSFER_FREEZE_v1.0.md`: external-transfer design frozen before results.
- `H10_IMPLEMENTATION_CORRECTION_v1.1.md`: narrow marker-boundary implementation fix.
- `CONFIRMED_NEAR_DUPLICATE_FAMILIES.tsv`: sanitized ID/score adjudication used to
  construct G-C; raw tweet text and reviewer identity are not redistributed.
